```
numeric →
divide(
    value: numeric
) → numeric
```

Returns the argument number divided by the parameter value. If the parameter value is `0`, it returns `null`.

## Parameters



| Name | Type | Required | Description |
|:-----|:-----|:---------|:------------|
| `value` | `numeric` | Yes | The value to divide the argument value. |
