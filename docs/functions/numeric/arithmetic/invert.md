```
numeric →
invert() → numeric
```

Returns the reciprocal of the argument number, meaning the result of the division of 1 by the argument number. If the argument value is `0`, it returns `null`.

## Parameters



This function has no parameters.





## Examples

```expressif
10 | invert → 0.1
```
