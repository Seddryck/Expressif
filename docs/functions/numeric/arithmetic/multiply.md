```
numeric →
multiply(
    value: numeric
) → numeric
```

Returns the argument number multiplied by the parameter value.

## Parameters



| Name | Type | Required | Description |
|:-----|:-----|:---------|:------------|
| `value` | `numeric` | Yes | The value to be multiplied by the argument value. |





## Examples

