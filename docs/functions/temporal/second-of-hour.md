```
date-time →
second-of-hour() → integer
```

returns a numeric value representing the seconds of the hour of the date passed as the argument

## Parameters



This function has no parameters.





## Examples

```expressif
#"2024-01-15 12:30:00" | second-of-hour → 1800
```
