| Name | Overview |
|:-----|:---------|
| [`count-distinct-chars`]({{ '/functions/text/counting/count-distinct-chars/' | relative_url }}) | Returns the count of distinct chars in the textual argument value. If the value is `null` or `empty` then it returns `0`. If the value is `blank` then it returns `-1`. |
| [`count-substring`]({{ '/functions/text/counting/count-substring/' | relative_url }}) | Returns the count of non-overlapping occurrences of a substring, defined as a parameter, in the argument value. |
