```
is-lower-case()
```

Returns `true` if all characters of the text value passed as argument are lower-case. The value `null`, `empty` and `whitespace` also returns `true`. Returns `false` otherwise.

## Parameters



This predicate has no parameters.





**Kind:** Predicate  
**Scope:** `text`
